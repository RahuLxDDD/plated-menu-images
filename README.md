# PLATED.

Browser-based menu image finder for restaurant menu workflows.

## Current version
- No local installation
- No Python / Terminal
- Searches Wikimedia Commons directly using the MediaWiki API with CORS
- Displays source/license/creator metadata
- Image selection and square crop editor
- 1080×1080 JPG export

## Hosting
This repository is intentionally a static site. It can be hosted on GitHub Pages, Vercel, Netlify or Cloudflare Pages without a build step.

## Image rights
Wikimedia Commons contains files under different free/open licenses and public-domain statuses. Check each file's source page and comply with its attribution/license terms before commercial publication.
